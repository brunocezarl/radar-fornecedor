# Editais abertos — materiais de limpeza e higiene — SP

Página pública, gratuita e sem login que lista os pregões eletrônicos **abertos no
estado de São Paulo** cujo objeto menciona materiais de limpeza, higiene ou
descartáveis — com a **lista de itens** de cada edital: quantidade, unidade,
valor unitário estimado e se a disputa é **exclusiva ou com cota para ME/EPP**.

- Página: https://brunocezarl.github.io/radar-fornecedor/
- Feed RSS: https://brunocezarl.github.io/radar-fornecedor/feed.xml

## De onde vêm os dados

Tudo vem do [PNCP](https://pncp.gov.br) — Portal Nacional de Contratações
Públicas, o portal oficial do governo federal. A coleta usa apenas a API pública,
com intervalo mínimo de 3 segundos entre requisições e respeito ao `Retry-After`.

## O que este site **não** é

- Não é revisão de edital. O filtro é automático, por palavra-chave no objeto.
- Os valores são **estimativas do órgão**, não preço praticado.
- Não avalia habilitação, nem elegibilidade, nem viabilidade de participação.
- Confira sempre o link oficial antes de qualquer decisão.
- Projeto independente, sem vínculo com órgãos públicos.

## Como é gerado

Arquivo estático, gerado automaticamente a partir de uma base local. Sem
rastreador, sem cookie, sem JavaScript de terceiros. A página é reescrita
periodicamente; commit automático é a atualização.
